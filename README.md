# RzzakFet v2.0 - المنظومة الذكية لإسناد وتوليد الجداول المدرسية

برنامج **RzzakFet** هو نظام متكامل ومتقدم مخصص للإدارة التربوية المغربية (الثانوي الإعدادي والتأهيلي)، يدمج محرك التوليد القوي **FET Solver** مع واجهة تفاعلية حديثة، ولوحة قيادة ذكية (**Bento Grid Hub**)، ونظام تدبير الامتحانات والحراسة العادلة، وموازنة حركية التلاميذ.

---

## 🌟 الميزات الرئيسية (الإصدار v2.0):
- **لوحة قيادة ذكية (Bento Grid Hub)**: نظرة شاملة تشغيلية على المؤسسة، البنية التربوية، حجم الحصص، وهيئة التدريس.
- **كفاية واستغلال القاعات والمختبرات**: تقييم آني ودقيق للطاقة الاستيعابية للقاعات العامة، المختبرات العلمية (PC / SVT)، قاعات الإعلاميات، الملاعب الرياضية، والقاعات المتخصصة المضافة من طرف المدير.
- **تدبير الامتحانات والمراقبة المستمرة (Exam Engine)**: حساب لجان الحراسة، القاعات المحجوزة، وتوزيع المترشحين وفق الضوابط الوزارية (المذكرة 031X26).
- **موازنة حركية التلاميذ (Student Mobility Engine)**: تتبع التدفقات، رصيد الدخول المدرسي، الوافدون، المغادرون، والمنقطعون مع ميزان الأسلاك والمستويات.
- **بنك القيود المرنة (68 قيداً FET)**: تفريغ النوافذ الذهبية للمجالس التعليمية، عدالة أنصاف الأيام، وتكافؤ توزيع الحصص.
